ℹ️ Logique des dossiers lue par l'outil
L'outil lit cette arborescence dans Dropbox :
/01_ALL MEDIAS ML 2026/ 01_MARS ML XXL PARIS/ ← événement Photographes Pro - …/ ← base photo 01_Timo-Leo - …/ ← personne JOUR 1 (13.03.26) - …/ ← slot + lien upload Videastes Pro - …/ ← base vidéo
Seuls le nom de l'événement, les dates des jours et les noms changent. Les libellés (Photographes Pro, JOUR N, PARTENAIRES, BAB & Montages) restent identiques.

Pour l'an prochain : crée un nouveau dossier racine (ex: /01_ALL MEDIAS ML 2027) en gardant exactement la même structure, puis change simplement le chemin ci-dessus. L'outil le lira automatiquement.
